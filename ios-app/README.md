# Igor VPN для iOS

Системный VPN-клиент OpenFlux с транспортом Mail.ru. Главная кнопка запускает
`NEPacketTunnelProvider`. IPv4 TCP направляется через выходной узел OpenFlux.
Настройки прямого доступа и автоматической проверки блокировок удалены.
Главный экран сохраняет кнопку-кольцо и статус; журнал VPN находится в
«Настройки → Диагностика». Журнал содержит запуск, смену состояния,
ошибки приложения, события транспорта и счётчики трафика.
После включения iOS сохраняет правило автоподключения. Выключение кнопкой
отключает и это правило. Список сайтов российского выхода хранится на
основном сервере 2.56.174.146; приложение не подключается ко второму
серверу напрямую.

Текущий выходной узел поддерживает IPv4 TCP. Для UDP/QUIC, кроме DNS,
клиент возвращает ошибку, чтобы приложение могло перейти на TCP. IPv6
захватывается, но не передаётся выходному узлу; ответы AAAA подавляются.
DNS разрешается расширением через DNS-over-TLS. Поэтому этот выпуск не
следует считать полнофункциональным VPN для всех протоколов.

## Сборка

На Mac с Xcode, XcodeGen, Go 1.26+ и настроенной подписью Apple запустите
`./build_ios_app.sh` из корня репозитория. Скрипт создаёт архив и IPA в
`ios-app/build/export`. На Linux или Windows можно проверить Go-часть,
но Xcode и подпись iOS там недоступны.

Используйте ссылку Mail.ru действующего L3 VPN-узла. Ссылки пользователей из
веб-панели относятся к proxy-узлу и с этим iOS-пакетным клиентом не работают.

Bundle ID сохранён: `com.p1neapplexpress-saharev.openflux`. Имя на экране —
Igor VPN. Для iOS 15+ требуется разрешение Network Extension.
