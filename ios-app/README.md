# Igor VPN для iOS

Системный VPN-клиент OpenFlux с транспортом Mail.ru. Главная кнопка запускает
`NEPacketTunnelProvider`. Трафик идёт напрямую по умолчанию. DNS-запросы
проверяются локально: если HTTPS-соединение с сайтом напрямую не удаётся,
клиент добавляет адрес сайта в маршруты VPN до ответа DNS. Есть ручные списки
«Всегда через VPN» и «Всегда напрямую»; прямой список имеет приоритет.

Автоматическая проверка приблизительна. Сайты со своим DNS-over-HTTPS,
приложения с IP без системного DNS и блокировки, возвращающие обычную
HTTPS-страницу, могут потребовать ручного правила. IPv6-ответы для сайтов,
выбранных для VPN, подавляются, так как выходной узел сейчас передаёт IPv4 TCP.
Изменения списков вступают в силу после переподключения. Главный экран
содержит кнопку-кольцо и статус; журнал VPN находится в «Настройки → Диагностика».

## Сборка

В GitHub Actions workflow «iOS build check» на macOS компилирует приложение
без подписи и сохраняет архив `IgorVPN-unsigned-iphoneos`. Он запускается
автоматически при отправке ветки `codex/igor-vpn-ios-build` или вручную из
вкладки Actions после добавления workflow в основную ветку. Архив без подписи
предназначен для проверки сборки; установить его на iPhone нельзя.

Для подписанного IPA нужны сертификат Apple и отдельные профили подготовки для
приложения и расширения Packet Tunnel. Оба профиля должны соответствовать
Bundle ID и команде в `project.yml`. Храните сертификат, пароль и профили в
GitHub Actions secrets, не в репозитории.

На Mac с Xcode, XcodeGen, Go 1.26+ и настроенной подписью Apple запустите
`./build_ios_app.sh` из корня репозитория. Скрипт создаёт архив и IPA в
`ios-app/build/export`. На Linux или Windows можно проверить Go-часть,
но Xcode и подпись iOS там недоступны.

Используйте ссылку Mail.ru действующего L3 VPN-узла. Ссылки пользователей из
веб-панели относятся к proxy-узлу и с этим iOS-пакетным клиентом не работают.

Bundle ID сохранён: `com.p1neapplexpress-saharev.openflux`. Имя на экране —
Igor VPN. Для iOS 15+ требуется разрешение Network Extension.
