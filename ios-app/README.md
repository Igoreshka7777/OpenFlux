# Igor VPN для iOS

Клиент использует персональную HTTPS-ссылку подписки из веб-панели OpenFlux. Подписка содержит WB Stream-комнату. Сервер 2.56.174.146 принимает VPN-трафик и направляет сайты из настроенного списка через российский выходной узел.

Ссылка привязывается к первому подключившемуся устройству. Для переноса на другой iPhone используйте «СМЕНИТЬ УСТРОЙСТВО» в панели и передайте новую ссылку.

Оформление главного экрана сохранено. Круг подключает и отключает VPN. Ссылка и журнал находятся в «Настройки». При неожиданном разрыве клиент повторяет подключение. iOS также хранит правило подключения по требованию.

## Сборка

На Mac требуются Xcode, XcodeGen, Go и доступная iOS-подпись. Запустите `./build_ios_app.sh` из корня репозитория; результат появится в `ios-app/build/export`. GitHub Actions проверяет сборку без подписи и выдаёт архив приложения, который нельзя установить на iPhone без подписи.

Bundle ID приложения: `com.p1neapplexpress-saharev.openflux`. Расширение: `com.p1neapplexpress-saharev.openflux.tunnel`. Для устройства оба идентификатора должны входить в профиль подписи с разрешением Packet Tunnel Network Extension.

Текущий транспорт обеспечивает TCP и DNS через туннель. UDP/QUIC и IPv6 пока не передаются через выходной узел, поэтому поддержка всех приложений и протоколов не гарантирована.
