# OpenFlux для OpenWrt

Клиент OpenFlux и панель LuCI: короткие ссылки подключения, журнал, каналы,
трафик, текущая скорость и список доменов для прямого доступа.

## Автоматическая установка

Подключитесь по SSH к **своему роутеру** и выполните:

```sh
curl -fL --proto '=https' --proto-redir '=https' https://github.com/Igoreshka7777/OpenFlux/releases/download/openwrt-v0.1.2-r2/install.sh -o /tmp/openflux-install.sh && sh /tmp/openflux-install.sh
```

Если curl отсутствует, установите `curl ca-bundle` из репозитория своей прошивки.
Установщик сам определяет архитектуру, загружает подходящий APK, проверяет
SHA-256 и цифровую подпись. Приватный ключ подписи в репозитории не хранится.
Перед установкой создаётся закрытая резервная копия настроек в `/root`.

Проверка совместимости без установки:

```sh
sh /tmp/openflux-install.sh --check
```

Загрузка и проверка пакета без установки:

```sh
sh /tmp/openflux-install.sh --download-only
```

Поддерживается **OpenWrt 25.12+ с APK**, 128 МБ RAM, 30 МБ свободного overlay.
Архитектуры: `aarch64_cortex-a53`, `aarch64_generic`, `x86_64`,
`arm_cortex-a7_neon-vfpv4`, `mipsel_24kc`. На более старой прошивке с opkg
скрипт остановится. Прошивку роутера он не обновляет.

## Подключение

Откройте **Службы → OpenFlux**, вставьте личную ссылку
`https://openfluxvpn.ru/s/…` или `csqtt://connect?…` и сохраните настройки.
Для первого подключения отключите другой VPN: основной маршрут должен идти
через WAN. Затем нажмите кнопку подключения OpenFlux.

Установщик не включает VPN и не переключает Amnezia. При обновлении сохраняются
личная ссылка и настройки; запущенный клиент нужно переподключить, чтобы
использовать новый бинарник. Первая установка создаёт выключенную конфигурацию.

При сбое OpenFlux трафик временно возвращается на основной маршрут. Интерфейс
показывает, когда OpenFlux отключён, когда он восстанавливается и через какой
интерфейс идёт основной маршрут. Счётчики относятся только к OpenFlux.
Транспорт обслуживает IPv4; публичный IPv6 блокируется при активном VPN,
кроме доменных исключений. Для исключений устройства должны использовать DNS роутера.

На Xiaomi Redmi AX6S проверены установка, LuCI и тестовые пакеты через туннель.
Проверка всей домашней сети напрямую через WAN пока не завершена. Другие
архитектуры собираются автоматически, но на физических устройствах не проверены.

## Сборка и публикация

GitHub Actions **OpenFlux OpenWrt** проверяет клиент и собирает пять пакетов.
Публикация запускается тегом `openwrt-v0.1.2-r2`. Секрет репозитория
`OPENWRT_SIGNING_KEY` содержит отдельный ключ APK. Он нужен только release job;
pull request проверки не получают ключ. Публичный ключ закреплён в установщике.
Для новой версии обновите номера в `install.sh`, `build-apk.sh` и README.

Исходники транспорта и лицензии включены в `vendor`; исходный модуль указан
в `NOTICE.txt`. Сертификаты iPhone и настройки других приложений не используются.

Сборка первого релиза выполнена отдельно: GitHub временно приостановил Actions
для этого форка. Для следующих автоматических релизов владелец должен снова
включить Actions на странице репозитория. Готовые пакеты устанавливаются независимо от Actions.
