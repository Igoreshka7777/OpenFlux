# OpenFlux для iOS

Исходный проект iOS-приложения OpenFlux, сборка 451. Интерфейс следует Android-версии: главный экран с кнопкой подключения, затем настройки со ссылкой, регулировкой параллельных потоков, журналом VPN и чатом поддержки.

В сборке 451 добавлен экран продления подписки с кнопками Telegram и ВКонтакте. Он открывается после подтверждения сервером, что срок доступа закончился. После продления пользователь нажимает «Я продлил — проверить доступ». При работающем VPN доступно уведомление об окончании подписки, если пользователь разрешил уведомления.

## Сборка на Mac

1. Установите Xcode, Go и XcodeGen.
2. Соберите сетевой мост в `WireGuardBridge` командой `make xcframework`.
3. В каталоге `VKTurnProxy` выполните `xcodegen generate` и откройте `VKTurnProxy.xcodeproj`.
4. Выберите свою команду Apple Developer для приложения и расширения VPN. Зарегистрируйте идентификаторы приложения и группу `group.org.igoreshka7777.openflux` с возможностями Network Extension и App Groups.
5. Соберите приложение в Xcode и проверьте подключение на iPhone до распространения.

Подробнее о текущем состоянии сборки: [OPENFLUX-STATUS.md](OPENFLUX-STATUS.md). В этом архиве находятся исходники, готового подписанного IPA нет.
