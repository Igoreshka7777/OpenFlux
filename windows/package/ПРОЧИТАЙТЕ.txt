OpenFlux для Windows 10/11 x64 — версия 1.0.2

1. Полностью распакуйте архив в отдельную папку.
2. Запустите OpenFlux.exe и разрешите запуск от администратора.
3. Откройте настройки, вставьте полную ссылку csqtt:// и сохраните.
4. Вернитесь на главный экран и нажмите на круг.

Для компьютера нужна отдельная ссылка клиента. Ссылка, уже привязанная
к телефону, может быть отклонена сервером как другое устройство.

В настройках доступны срок подписки, поддержка, журнал и число потоков.
Подписка и чат доступны для основного сервера OpenFlux.
Если VK попросит проверку, выполните её в отдельном окне.
Для проверки нужен Microsoft Edge WebView2 Runtime:
https://developer.microsoft.com/microsoft-edge/webview2/

Ссылка хранится зашифрованной в профиле Windows. В приложение не встроены
пользовательские пароли, токены или готовые ссылки подключения.

В этой версии туннель передаёт IPv4. На время подключения IPv6 блокируется,
чтобы приложения не обходили VPN. После отключения блокировка снимается.
VPN не подключается автоматически при запуске Windows.

Если после аварийного завершения осталась проблема с интернетом,
откройте настройки OpenFlux и нажмите «Восстановить сеть».
Обычное закрытие программы сначала отключает VPN и очищает его маршруты.

Приложение не подписано сертификатом издателя.
Не удаляйте файлы DLL и openflux-core.exe из папки программы.

Изменения 1.0.1:
- Убрано двойное отображение журнала и повторное открытие проверки VK.
- Проверка VK больше не расходует время ожидания подключения.
- Причина отключения сохраняется на главном экране и в журнале.
- Журнал можно сохранить кнопкой «Сохранить журнал в файл».

Исправление 1.0.2: устранён отказ Windows при создании правила IPv6, из-за которого VPN останавливался после получения конфигурации.
